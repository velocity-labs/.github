# Security policy

This policy covers every Velocity Labs repository that doesn't have its own, including the velocitylabs.io website and our open source projects.

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead:

- **On GitHub:** choose "Report a vulnerability" on the repository's Security tab.
- **By email:** contact@velocitylabs.io

Tell us the project and version, what you found, and how to reproduce it, ideally with a script or steps we can run. Reports written with the help of AI tools are welcome, as long as the reproduction works.

We'll reply within 3 business days and keep you updated while we work on a fix. When we publish an advisory, we'll credit you unless you'd rather we didn't.

## Supported versions

Only the latest release of each project gets security fixes. For the velocitylabs.io website, that's the live site.

## Testing velocitylabs.io

Please don't run denial-of-service tests or high-volume automated scans against the live site, and don't send more through the contact form than you need to show the problem.

## Apps we build for clients

This policy doesn't cover the applications we build or maintain for clients. If you've found a problem in one of them, email us and we'll pass it to the client.
